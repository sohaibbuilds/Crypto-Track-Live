# 💰 CryptoTrack Live

A real-time cryptocurrency dashboard with live prices, a mock portfolio tracker, price alerts, and a sleek dark/light UI.

## ✨ Features
- Live crypto prices via CoinGecko API (auto-refresh every 60s)
- Scrolling ticker bar with top coins
- Portfolio tracker with localStorage persistence
- Custom price alerts
- Dark/Light mode toggle
- Fully responsive with mobile nav

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (Fetch API)
- CoinGecko API

## 🚀 How to Use
1. Clone or download this repo
2. Open `index.html` in your browser
3. No build steps or API key needed — CoinGecko's public API is free
